# FitLingo · 健身激励打卡 App

一个面向「三分钟热度」泛健身人群的激励打卡交互原型。由黑猫 IP「小黑」全程陪伴，用多邻国式的连胜、徽章、日历点亮、补卡机制，建立持续的正反馈，把「坚持运动」变成一件轻松有趣的小事。

## 快速运行

单文件自包含原型，无需构建、无需安装依赖：

- 直接双击打开 `index.html`（或拖进浏览器即可）
- 也可以起一个本地静态服务：`python3 -m http.server 8000` 后访问 `http://localhost:8000`

所有图片、动画、字体均已内嵌为 base64，**零外部请求**，离线也能完整运行。

## 功能一览

- **开屏品牌展示** + 三步引导：名字 / 一周几练 / 提醒时间
- **首页打卡舞台**：俯卧撑、杠铃卧推等动作动画 + 打字机气泡陪伴
- **打卡记录**：今天完成的动作以动画形式散落在首页，像桌宠一样「看得见」
- **激励体系**：连胜 Streak、徽章解锁、日历点亮、补卡
- **其他**：个人资料、提醒设置、海报分享等

## 技术

- 纯原生 HTML / CSS / JavaScript，零框架、零依赖
- 单文件即开即用，便于迁移、评审与演示
